## 1. Objective

The objective of this assignment is to understand the basic concepts of linear algebra and learn how vectors, matrices, and dot products are used in Machine Learning.

## 2. What Is Linear Algebra?

Linear algebra is a branch of mathematics that deals with vectors, matrices, and mathematical operations between them.

It is important in Machine Learning because data is often represented in numerical form.

**Example:** A house can be represented using its size, number of bedrooms, and number of bathrooms.

## 3. What Is a Vector?

A vector is an ordered collection of numbers.

**Example:**

`[1200, 3, 2]`

This vector represents a house with:
- Size: 1200 square feet
- Bedrooms: 3
- Bathrooms: 2

In Machine Learning, vectors can represent the features of a single data example.

## 4. What Is a Matrix?

A matrix is a rectangular arrangement of numbers in rows and columns.

**Example:**

```text
[
  [1200, 3, 2],
  [1500, 4, 2],
  [1800, 4, 3]
]
```

Each row represents a house, while each column represents a feature.

- Column 1: House size
- Column 2: Number of bedrooms
- Column 3: Number of bathrooms

Matrices are useful for storing multiple data examples.

## 5. What Is a Dot Product?

The dot product is an operation that multiplies corresponding elements of two vectors and then adds the results.

**Example:**

Vector A: `[2, 3]`

Vector B: `[4, 5]`

Calculation:

`(2 × 4) + (3 × 5) = 8 + 15 = 23`

**Answer:** The dot product is `23`.

Dot products are used in many Machine Learning calculations, including neural networks and linear models.

## 6. Why Is Linear Algebra Important in Machine Learning?

Linear algebra helps Machine Learning models:
- Represent data numerically.
- Store multiple examples using matrices.
- Perform calculations on features.
- Calculate predictions using mathematical operations.
