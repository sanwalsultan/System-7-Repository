## 2. What Are Model Predictions?

A prediction is the output generated by a trained Machine Learning model for new input data.

**Example:** A model receives the size of a house and predicts its price.

- Input feature: House size
- Trained model: Linear Regression
- Output: Predicted house price

Predictions help us use patterns learned from existing data to estimate outcomes for new examples.

## 3. What Are Model Coefficients?

In Linear Regression, coefficients represent how the predicted value changes with an input feature, while other features are held constant.

**Example:** In a house-price model, the coefficient for house size indicates how the predicted price changes for a one-unit increase in size, assuming other features remain unchanged.

The interpretation depends on the feature's units and the model.

## 4. What Is Feature Importance?

Feature importance helps identify which input features contribute most to a model's predictions according to a particular importance method.

**Example:** A house-price model may use:
- House size
- Number of bedrooms
- Location
- Number of bathrooms

Feature importance can help us understand which features the model relies on most.

**Important:** Feature importance does not necessarily prove that a feature causes a change in the target.

## 7. Model Evaluation

Use suitable metrics to evaluate each project.

### Regression
- **Mean Absolute Error (MAE):** Measures the average absolute difference between actual and predicted values.
- **R² score:** Measures how well the model explains variation in the target relative to a baseline.

### Classification
- **Accuracy:** The proportion of predictions that are correct.
- **Precision:** The proportion of positive predictions that are actually positive.
- **Recall:** The proportion of actual positive cases correctly identified.

Choose metrics that fit the problem, especially when classes are imbalanced.

## 8. Practice Questions and Answers

**Q1. What is a model prediction?**  
The output generated by a trained model for given input data.

**Q2. What is a model coefficient?**  
A numerical value that describes a feature's contribution to a linear model's prediction, under the model's assumptions.

**Q3. What is feature importance?**  
A measure used to estimate how important a feature is to a model's predictions.

**Q4. What is regression used for?**  
Predicting numerical values, such as house prices.

**Q5. What is classification used for?**  
Predicting categories, such as spam or not spam.

**Q6. What is Scikit-learn?**  
A Python library for building and evaluating Machine Learning models.

**Q7. Why do we split data into training and testing sets?**  
To train a model and evaluate its performance on data not used for training.

**Q8. What does MAE measure?**  
The average absolute difference between actual and predicted numerical values.

**Q9. What does classification accuracy measure?**  
The proportion of predictions that are correct.

**Q10. Does feature importance prove causation?**  
No. It describes a model's use of features, not necessarily cause-and-effect relationships.
